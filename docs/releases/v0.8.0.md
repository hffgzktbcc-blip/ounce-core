# Ounce Core v0.8.0

Makes the workbench and the Mac app one clear front door, widens what they can check, and removes
code that did not belong in a homebrew verification tool. Verification and conformance claims are
unchanged: nothing here claims independent reproduction, Neoverse conformance or general libc
compatibility.

## Changed

- The Mac app is one window: the workbench. Drop a program anywhere on it or on the Dock icon.
  Menus are File, View (Advanced inside) and Help. The Mac app is still built from source; this
  release has no prebuilt app download.
- The workbench page and the app use the same words: "Results match", "Results differ",
  "Could not run this program".
- Report This Problem, Copy details and Help > Report a Problem fill in every field the app
  knows (program, hash, engine, expected, observed, reproduce command, OS, chip, version).
  Nothing is sent until you press Submit.
- README and site rewritten to be shorter and clearer.
- Floating-point: FPSR exception flags are set by FP arithmetic, conversions, FRINT*, compares and
  FMAX/FMIN in the interpreter and Tier-3; FP arithmetic now always uses the soft-float path, so
  interpreter FP is slower than before (not measured). See CHANGELOG.md for limits.

## Added

- Static AArch64 Linux ELF programs can be checked from the workbench and the Mac app.
- Welcome, claim and nudge workflows for contributors.

## Removed

- Key handling and encrypted-container (NCA/XCI) support, with a CI guard against its return.

## Limits

- Dock drop while the app is not running, drop onto the window, and Intel Macs were not verified.
- fp-edge hardware results are recorded in docs/verify/fp-edge/README.md.

# Ounce-Core v0.5.0

- Frame oracles reject empty pixel assertions, invalid probes and unreachable frame
  indices. Raw reports retain observed probe coordinates and RGBA values.
- Ounce-Verify preserves malformed per-workload evidence while allowing the other
  cases to finish. Its HBLauncher report validator recomputes registered pixel
  verdicts and enforces source identity and complete engine coverage.
- HID no longer invents controller colors. Unknown color metadata is reported as
  unavailable; metadata supplied through the host feed is published and refreshed.
- A pinned outside HBLauncher Hello CPU package executes on Interpreter and Tier-3.
  Both engines match four registered first-frame pixels and agree on the complete
  software-rendered frame. Structured reports retain package and oracle hashes.

The HBLauncher result exercises AArch64 guest code and host UI callbacks. It does
not establish Switch 2 GPU-path, arbitrary homebrew or commercial-software support.
The original-Switch corpus metric is maintained separately from this SDK-path check.

Linux x86-64, macOS arm64 and Windows x86-64 CLI archives are built and tested from
Cargo.lock. Release publication waits for all platform jobs; SHA256SUMS covers every
archive. Optional native execution, Tier-4 and GPU-presentation features retain their
separate feature-specific CI checks.

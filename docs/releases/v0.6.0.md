# Ounce Core v0.6.0

Release candidate; publication and downloadable assets are not yet available.

- Diagnose the first differing compared instruction in a hardware trace with
  `fuzz-replay --first-difference NEWDIR`, preserving exact input/reference/actual
  registers and content hashes. This is independent-instruction diagnosis, not
  arbitrary-program first-divergence tracing.
- Replay content-checked instruction dossiers with `replay-instruction BUNDLE`.
  Historical reproduction and agreement with hardware are separate verdicts.
- Fix vector FMUL default-NaN signs for zero multiplied by infinity. The original
  hardware reference and failing dossiers remain unchanged.
- Run the pinned LZ4/musl Linux ARM64 ELF workflow on Linux, macOS and Windows.
  `run-elf --deterministic` supplies bounded virtual clocks; arguments following
  `--` reach the guest unchanged. General Linux application support is unproven.
- Step actual ARM64 instructions in the [live WebAssembly playground](https://hffgzktbcc-blip.github.io/ounce-core/playground/).
- Reuse the versioned one-case hardware conformance seed in `conformance/`.
  All three hosted OSes pass; outside-project adoption remains outstanding.

The normal release packages default-feature CLI binaries for Linux x86-64,
macOS arm64 and Windows x86-64, with source/dependency/font notices, binary-bound
Rust toolchain notices, installed Linux shared-library copyright/licence texts, checksums and provenance attestations. The native Mac app,
optional GPU/native-execution/JIT features and arbitrary-program compatibility
are outside these archives.

Publication requires the actual recorded distribution review and final platform
qualification. Release qualification can be run without publishing binaries;
its reports explicitly preserve pending review status. No test or generated
reviewer identity substitutes for a completed distribution decision.

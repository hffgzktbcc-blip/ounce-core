# ounce-core v0.11.0 — release notes (published 2026-11-23)

**Ounce-Core runs supported ARM64 programs on three CPU engines, compares their results with references recorded on real ARM64 hardware, and helps developers investigate differences.**

Version **v0.11.0**, released **23 November 2026**, delivers zero-system-dependency pure-Rust headless builds, a typed Rust library API, pure JSON stdout reporting, full scalar half-precision (FP16) support, and a 5.92M-vector Berkeley TestFloat 3e differential sweep with zero real mismatches.

## Highlights

- **Pure-Rust headless builds by default.** `default = []` removes `cpal` (ALSA) and `gilrs` (libudev) from default builds so Linux/macOS/Windows binaries compile and run with zero C system libraries. Desktop audio and controller input remain available via `--features host-io` (`#550`).
- **Typed Rust library API & pure JSON stdout.** `src/lib.rs` (`#![forbid(unsafe_code)]`) exposes `EngineKind`, `RunOptions`, `StopReport`, `StopClass`, `run_elf`, and `run_nro` (`#539`). `--report-json=-` emits pure `ounce.run.v1` JSON to `stdout` with diagnostics routed to `stderr` (`#537`), alongside zero-dep ELF symbolication and frame-pointer backtraces (`#531`).
- **Full scalar FP16 and vector/syscall fixes.** Scalar FP16 arithmetic, `FCVT`, `FMOV H<->W/X`, `#imm`, `FRINT* H`, and `int<->half` conversions (`#531`, `#553`, `#554`), vector `.4H`/`.8H` `FABS`/`FNEG` (`#543`), `LD2–LD4`/`ST2–ST4`/`LD2R–LD4R` (`#547`), and Linux syscalls `tkill`/`tgkill` (`128+signal` exits, `#549`) and `newfstatat` (`#551`).
- **5.92M-vector differential FP & compiler/library sweeps (measured on `baec66b`).** Berkeley TestFloat 3e (`ARM-VFPv2`, tininess before rounding) passed `5,921,280` vectors across all 9 groups with `0` real mismatches vs `qemu-aarch64`, alongside Csmith (`2,815` compared, `0` differ), YARPGen (`498/500`), `gcc.c-torture/execute` (`1,586`–`1,602`), `PolyBench/C` (`60/60`), MicroPython (`581/582`), `libpng` (`168/168`), `libdeflate` (`1,800` round-trips), `bzip2` (`140/140`), `brotli` (`205/205`), `PCRE2` (`51/51`), and `102/102` paper checks.
- **Try a release build.** Download archives for Linux x86-64, Linux ARM64, macOS ARM64, or Windows x86-64 with SHA-256 checksums and SPDX 2.3 SBOMs.

**Important limits:** Ounce-Core supports bounded test workloads, not arbitrary ARM64 applications. Matching results apply to the inputs tested, and **no external developer has independently reproduced these release results yet**.

## Technical changes

### Library API, diagnostics, and build hardening

- **Typed Rust library API (`#539`):** `src/lib.rs` exposes `EngineKind`, `RunOptions`, `StopReport`, `StopClass`, `run_elf`, and `run_nro`, with `src/main.rs` as a thin CLI wrapper.
- **Pure JSON stdout (`#537`):** `--report-json=-` writes `ounce.run.v1` JSON cleanly to `stdout` while routing CLI banners and `run_file` diagnostics to `stderr` ([schema](../OUNCE_RUN_V1_SCHEMA.md)).
- **ELF symbolication & backtraces (`#531`):** Zero-dependency ELF symbol table lookup and frame-pointer backtrace reporting on stops.
- **Zero-sys-dep headless default (`#550`):** `cpal` and `gilrs` moved behind opt-in `--features host-io`; release Linux binaries link zero ALSA/udev shared libraries.
- **Workspace safety lints & CI slimming (`#538`, `#541`, `#548`):** Enforced `unsafe_op_in_unsafe_fn`, `undocumented_unsafe_blocks`, and `missing_safety_doc` across workspace crates; pruned obsolete workflows and switched PR ARM64 ELF matrix runs to a fast smoke slice (`push: [main]` runs all 51 harnesses).

### CPU and Linux ELF support

- **Scalar FP16 (`#531`, `#553`, `#554`):** Decode and execution for `FADD`, `FSUB`, `FMUL`, `FDIV`, `FNMUL`, `FSQRT`, `FMOV`, `FABS`, `FNEG`, `FCVT` (`H <-> S/D`), `FCSEL`, `FCMP`, `FCCMP`, `FMOV H<->W/X`, `FMOV #imm`, `FRINT* H`, and integer / fixed-point `int <-> half` conversions, including Apple Silicon-verified `FPConvert` `FZ`/`FZ16` behaviour in `softfp::convert`.
- **Vector & structure loads/stores (`#543`, `#547`):** Vector `FABS`/`FNEG` on `.4H`/`.8H` lanes with `sNaN` handling, plus `LD2–LD4`/`ST2–ST4` single-structure and `LD2R–LD4R` replicate instructions.
- **Linux syscalls (`#549`, `#551`):** `tkill`/`tgkill` to self (`128+signal` exit status for `abort()`/`raise()`) and `newfstatat` path handling returning `ENOENT` like `openat`.

### Differential verification summary (measured on `baec66b`)

- **Berkeley TestFloat 3e (`ARM-VFPv2`, tininess before rounding):** `5,921,280` vectors across all 9 groups (`f16`/`f32`/`f64` arithmetic, FMA, `f16<->f32/f64`, `int<->half`, `float<->int`) with `0` real mismatches vs `qemu-aarch64`; `656` FMA NaN-priority payload cases match `qemu-aarch64` (6 sampled confirmed addend-NaN on Apple M3). Plus `144/144` `FPCR.FZ`/`FZ16`/`DN` cases and `908/908` scalar `f16` `FMOV`/`#imm`/fixed-point checks across Interpreter, Tier-3, and Tier-4.
- **Compiler & fuzzing stress vs `qemu-aarch64`:** Csmith 2.4.0 (`2,815` compared across `-O1`–`-O3 -mcpu=apple_m1`, `0` differ; `385` timed out under QEMU), YARPGen v2 (`498/500`; 2 exceeded instruction budget), `gcc.c-torture/execute` (`1,586` at `-O0`, `1,602` at `-O2` and `-O3 -mcpu=apple_m1`; 3 temp-file tests differ), CompCert `test/c` (`69/72`; `knucleotide` needs `stdin`), `PolyBench/C` (`60/60` vs QEMU and native x86), `musl libc-test` (`276` pass with identical stdout; `198/199` math; 48 differ on unsupported threads/files/signals).
- **Numerics, science & paper checks:** Kahan `Paranoia` (`4/4`), Shewchuk adaptive predicates (`90,000` near-degenerate cases, `0` mismatches vs exact/QEMU/x86), physics/quantum invariants (Kepler, Crank-Nicolson tunnelling, 2D Ising, Grover, QFT: `9/9`), and `102/102` [paper checks](../verify/papers/README.md) comparing ARM64 output against published numbers and a native host build.
- **Real libraries & VMs:** MicroPython (`581/582` `tests/basics` vs QEMU), QuickJS (`5/5` at `-O3 -mcpu=apple_m1`), `libpng 1.6.59` (`168/168`), `libdeflate` (`1,800` round-trips, `0` failures; `1.25M` vs `17.8M` instructions proving `CRC32`/`PMULL`/`EOR3`), `bzip2` (`140/140`), `brotli` (`205/205`), `PCRE2` (`51/51` patterns, `78` matches), plus the 51-harness Linux ARM64 ELF CI matrix and `50/50` first-frame NRO oracle corpus.

## What this release does not claim

- The large `baec66b` differential sweeps primarily compare `ounce-core` against `qemu-aarch64` and host reference builds, with native Apple M3 spot-checks for FMA NaN priority, `#543`, `#547`, and the 199-op FP workload. They establish bounded equivalence on tested inputs, not full ISA or hardware proof ([LIMITS.md](../LIMITS.md)).
- Remaining unimplemented vector `f16` / special FP instructions (such as `FRECPE`/`FRSQRTE`/`FRECPS`/`FABD`/`FCMEQ #0` and remaining vector `f16` forms) are deferred past `v0.11.0`.
- Dynamic linking, multi-threaded Linux ELF execution, and arbitrary GUI/network applications remain out of scope.

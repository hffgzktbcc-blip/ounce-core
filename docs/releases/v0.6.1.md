# Ounce Core v0.6.1

Maintenance release on v0.6.0. No new features and no change to the verification or
conformance claims.

- Fix ASTC texture decoding: the bilinear weight underflowed in `u32` when
  `fs + ft > 16`, panicking debug builds. Release-build behaviour is unchanged.
- Tier-4: an instruction the lowerer rejects now rolls the block back, so the Tier-3
  fallback sees no partial effect.
- CI action updates (`actions/setup-python` 7, `actions/dependency-review-action` 5)
  and removal of compiler warnings in default and `nce native-jit` builds.

Packaging, notice coverage and scope are the same as
[v0.6.0](https://github.com/hffgzktbcc-blip/ounce-core/releases/tag/v0.6.0): default-feature
CLI binaries for Linux x86-64, macOS arm64 and Windows x86-64, with notices, checksums and
provenance attestations. The native Mac app and optional GPU/native-execution/JIT features
are outside these archives. The release workflow verifies the archives and notice
coverage before publication; no new legal review or third-party grant is claimed.

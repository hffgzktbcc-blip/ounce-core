# Bundled font

`DejaVuSans.ttf` is DejaVu Sans 2.37 (Bitstream Vera derivative, free licence: see `DejaVu-LICENSE.txt`),
taken unmodified from https://github.com/dejavu-fonts/dejavu-fonts/releases/tag/version_2_37.
SHA-256: `7da195a74c55bef988d0d48f9508bd5d849425c1770dba5d7bfc6ce9ed848954`.

`pl:u` serves it as the shared font, so homebrew that asks for one gets an open-licensed font.
No retail font is, or will be, bundled.

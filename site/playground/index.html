ARM64 Browser Playground

The playground compiles the safe Rust AArch64 CPU interpreter and memory model to WebAssembly. A browser loads the engine and steps instructions directly, displaying actual register snapshots rather than scripted animations.

Build and run locally

To run the compiled WebAssembly playground offline on your computer, build it from the repository checkout:

# 1. Add WebAssembly target and install the pinned wasm-bindgen CLI (0.2.129)
rustup target add wasm32-unknown-unknown
cargo install wasm-bindgen-cli --version 0.2.129 --locked

# 2. Build the browser package
scripts/build_playground.sh

# 3. Serve the generated bundle
python3 -m http.server 8090 --bind 127.0.0.1 --directory target/playground

Open http://127.0.0.1:8090/ in your browser. Details, memory boundaries and tested browser scope are documented in docs/PLAYGROUND.md.

Scope and limits

The playground exercises an interpreter subset: 256 instruction words, an 8 KiB text input cap, a 4 KiB code page and 4 KiB stack, and a 10,000 total step ceiling. No operating system services, JIT, or full floating-point exception trap semantics are provided in this mode. It is a learning and inspection tool, not a correctness certificate.

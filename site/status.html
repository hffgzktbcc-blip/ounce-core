Ounce-Core: current status and research evidence

This page is the maintained entry point for readers encountering old launch-day articles, mirrored repository snapshots or outdated search snippets. Check linked GitHub records for the latest run and publication date rather than treating a historic figure as a live counter.

Scope: Ounce-Core is an experimental Rust AArch64 runtime and verification research platform for appropriately licensed original-Switch homebrew and synthetic workloads. It is not a generally compatible Switch 2 emulator; commercial game compatibility is not demonstrated.

What has progressed since the October 2026 launch?

  • Expanded original-Switch test corpus: work on 50 externally sourced homebrew programs is documented in the project plan and external-corpus CI runs. The exact passing count must be taken from the most recent canonical Ounce-Verify report; corpus size alone is not the pass count.
  • Interpreter and Tier-3: published first-frame oracle results use registered pixel checks and artifact-integrity verification. See what is proven and oracle methodology.
  • Ounce-Verify: evidence-preserving diagnosis, comparison and replay tools support auditable experiments. See verification documentation.
  • Mac research experience: native launcher and graphics paths have been worked on, with separately qualified guest-frame and GPU readback observations. See graphics scope.
  • Limited Switch 2 work: distinct experimental homebrew/SDK-path observations are documented separately from original-Switch corpus results; they are not evidence of commercial software support.

Read primary evidence, not a frozen milestone

  • Latest external homebrew corpus workflow — run status and downloadable evidence when available
  • Living development plan — milestone links and explicit limitations
  • Official releases — versioned announcements and assets
  • Pull requests — unmerged work is not a shipped capability
  • Independent Tester Challenge — outside reports are counted separately, not folded into internal CI metrics

Corrections for old search results

The launch-day state is part of the history, but it is not a description of the current code. An early article may be accurate about what was present in October while omitting subsequent releases, testing and architecture changes. This page does not demand removal of historical criticism or claim that newer work retrospectively validates earlier assertions.

For researchers and journalists: cite the relevant commit SHA, release, workflow run ID, registered oracle and execution engine. Distinguish an internally reproduced test from an independent outside rerun. Please link directly to this page and the primary artifact when reporting new results.

Help us understand why ARM64 programs fail — and prove when they work.

Ounce-Core is an experimental Rust AArch64 execution and verification laboratory. You can help with documentation in a browser, contribute systems code, or independently reproduce a hardware result. No collaborator access is needed to submit a pull request.

Help-wanted issues

Your first contribution in four steps

  1. Pick an open starter task and check that no one already has a PR for it.
  2. Use GitHub's browser editor to propose the requested Markdown or HTML improvement in your fork, or use a local checkout for code tasks.
  3. Submit a pull request with a concise description, what you checked, and what you could not verify.
  4. A maintainer reviews it; a successful PR never automatically certifies emulator correctness or independent reproduction.

New to the architecture? Start with the five-step reader guide, the glossary, or our research preprint.

What we promise: a genuine, reviewable path to helping. We do not promise that every ARM64 program runs, that outside reproduction has already been established, or that volunteer work earns repository write access. Read the scientific limits and community code of conduct.

# Third-party material

Prebuilt fixtures in `tests/fixtures/nro/` link the following. Licence texts are from the upstream projects;
copy the exact files for the versions used before any release (not yet done).

- **libnx**: ISC licence (https://github.com/switchbrew/libnx).
- **newlib**: BSD-style licences, per file (https://sourceware.org/newlib/).
- **GCC runtime libraries** (libgcc, libstdc++): GPL with the GCC Runtime Library Exception.
- **Rust crates**: see `Cargo.lock`. A licence audit is not yet recorded (see `docs/PROVENANCE.md`).

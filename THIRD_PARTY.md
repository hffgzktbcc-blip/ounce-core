# Third-party material

Prebuilt fixtures in `tests/fixtures/nro/` link the following. Exact fixture-toolchain versions and
binary hashes are recorded in `tests/fixtures/nro/TOOLCHAIN_VERSIONS.md`.

- **libnx**: ISC licence (https://github.com/switchbrew/libnx).
- **newlib**: BSD-style licences, per file (https://sourceware.org/newlib/).
- **GCC runtime libraries** (libgcc, libstdc++): GPL with the GCC Runtime Library Exception.
- **Rust crates**: see `Cargo.lock` and `docs/DEPENDENCY_LICENSE_AUDIT.md` (audit completed 2026-10-28).
